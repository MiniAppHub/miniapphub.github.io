Мини-приложения
живут в одной оболочке

MiniAppHub — платформа, где HTML5-приложение упаковывается в репозиторий, публикуется через GitHub и запускается в песочнице на телефоне и на компьютере. Разработчикам — бесплатный хостинг и автоматические релизы. Пользователям — один каталог.

Как это устроено

Оболочка без интерфейса

Приложение для Android и Windows — это окно с одной iframe-песочницей. Весь интерфейс рисует мини-приложение, назначенное лаунчером.

Мини-приложение — обычный сайт

Чистый HTML, CSS и JavaScript без сборки. Манифест описывает id, версию, иконку и запрашиваемые разрешения.

Публикация через GitHub

Fork шаблона, тег vX.Y.Z — и релиз с архивом собирается сам, а запись в каталоге обновляется роботом.

Мост API вместо нативных SDK

Мини-приложение общается с оболочкой через postMessage. Одно действие — один файл, который оболочка подгружает динамически.

// внутри мини-приложения
import {{ mapp }} from './api/sdk.js';

const settings = await mapp.shell('getSettings');
await mapp.shell('setSettings', {{ theme: 'light' }});
await mapp.apps('installApp', {{ id: 'headmad.qr-tools' }});

Ответ всегда в форме { ok, result | error }, как в Telegram Bot API.
